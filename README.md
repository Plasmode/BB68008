# BB68008 Barebones 68008 SBC
Barebones 68008 is a very simple 68008 SBC similar to barebones Z80 and barebones 6502.  There are only 3 IC in BB68008, MC68008 CPU, 512K RAM, and GAL22V10.  Currently there is no PCB version of BB68008, only a [prototype](Prototype) constructed on modified BB6580 pc board.
